## Brand & Style

This design system is engineered for high-stakes IT infrastructure management. It adopts an **Experimental "Command Center"** aesthetic that bridges the gap between sophisticated enterprise software and developer-focused IDEs. The brand personality is rooted in precision, technical authority, and "heads-down" efficiency.

The target audience consists of System Administrators and IT Directors who manage high volumes of hardware and software licenses. The UI evokes a sense of total control through a deep dark-mode interface, high information density, and monospaced technical accents. The style leverages a **Technical Minimalism**—stripping away decorative fluff in favor of structural clarity, rigid grid alignments, and subtle glowing status indicators that mimic server rack LEDs.

## Colors

The palette is anchored by the seed color `#020617`, creating a profound "Ink Black" foundation that reduces eye strain during long periods of monitoring. 

- **Primary Neutral:** Deep Navy and Slate Grays form the structural hierarchy. Surfaces are layered using slightly lighter shades of navy to indicate elevation.
- **Accents:** High-vibrancy semantic colors are used sparingly for status indicators. 
    - **Active/Healthy:** A piercing emerald green.
    - **Maintenance:** A warm, industrial amber.
    - **Urgent/Offline:** A sharp, critical red.
- **Data Accents:** Subtle blue tints are used for interactive elements like links and primary buttons to distinguish them from static data.

## Typography

This system utilizes a dual-font strategy to balance readability with a technical aesthetic.

1.  **Geist (Headlines):** Used for all structural headings and page titles. Its clean, geometric sans-serif terminals provide a professional, corporate tech feel.
2.  **JetBrains Mono (Body & UI):** Used for all data points, asset IDs, table content, and labels. The monospaced nature ensures that columns of numbers and serial keys align perfectly, facilitating rapid scanning of technical specifications.

**Scaling:** For mobile devices, `display-lg` and `headline-lg` should scale down by 25% to maintain visual balance on smaller screens.

## Layout & Spacing

The layout is built on a **12-column rigid grid** optimized for high-density data visualization. 

- **Density:** The system prioritizes "Information Density" over whitespace. Padding is kept tight (`8px` to `16px`) to allow more assets to be visible on a single screen without scrolling.
- **Sidebar:** A fixed left-hand navigation rail (64px collapsed, 240px expanded) provides constant access to asset categories.
- **Grid Behavior:** On desktop, use a fixed-fluid hybrid; sidebars are fixed, while the main content area expands to a maximum width of 1600px. On tablet and mobile, columns collapse into a single-column vertical stack with horizontal swiping for data tables.
- **Rhythm:** All vertical spacing must be a multiple of `4px`.

## Elevation & Depth

In this dark-mode, developer-centric environment, elevation is conveyed through **Tonal Layering** and **Subtle Outlines** rather than shadows.

1.  **Base Layer:** `#020617` (Global background).
2.  **Surface Layer:** `#0f172a` (Cards, sidebars, and panels).
3.  **Active/Hover State:** `#1e293b` (Subtle lightening of the surface).
4.  **Borders:** Use 1px solid strokes in `#1e293b` for all containers. This creates a "blueprint" or "schematic" look that feels engineered.
5.  **Focus States:** Use a 1px solid primary blue border with a 2px outer glow (0.15 opacity) to simulate an illuminated hardware button.

## Shapes

The design system uses a **Soft (1)** roundedness profile to maintain a professional, hardware-integrated appearance. 

- **Standard Elements:** Buttons, input fields, and small tags use `0.25rem` (4px) corner radius. This is enough to feel modern without losing the "industrial" precision of sharp edges.
- **Large Containers:** Cards and modal dialogs use `rounded-lg` (`0.5rem`) to slightly soften the large blocks of dark color.
- **Status Pills:** Status indicators (e.g., "Active") use a slightly higher radius or full pill shape to distinguish them from interactive buttons.

## Components

### Buttons
- **Primary:** Solid slate-blue background with white JetBrains Mono text. No gradients. 
- **Secondary/Ghost:** 1px border matching the text color, transparent background.
- **Size:** Compact (32px height) for high-density layouts.

### Asset Cards
- Structured with a header containing the Asset ID in `code-label` style.
- Body text uses `body-sm` for specifications (CPU, RAM, Storage).
- Footer contains a single "Status LED"—a colored circle next to a label.

### Data Tables
- The "Workhorse" of the system. 
- Row borders only (no vertical lines) using `#1e293b`.
- Alternating row stripes (zebra striping) using a very subtle `#0f172a` and `#020617` shift.
- Column headers are `code-label` with `0.4` opacity.

### Input Fields
- Dark backgrounds (`#020617`) with a 1px border.
- Floating labels in `body-sm` that shrink to `code-label` on focus.
- Monospaced text entry to ensure alignment of serial numbers and IP addresses.

### Status Indicators (LEDs)
- Small 8px circles with a 4px "bloom" (outer glow) in the semantic color to indicate live status.
